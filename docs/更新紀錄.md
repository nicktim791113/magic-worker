## 2026-06-02

- 🛠️ 新增**開發者模式（關卡編輯器）**：用滑鼠在格線上「畫」關卡（地形 / 金幣 / 起點 / 終點 / 擦除），
  可即時試玩、匯出 JSON、每一步自動存在瀏覽器。進入方式：網址加 `?dev`，或遊戲中按 `E` 切換。
- 🧱 關卡改為**資料驅動**：把關卡內容搬到 `src/levels/levels.js`（用格子座標 col/row 描述），
  場景改成「讀資料來蓋關」，取代以前寫死的 `addGround / addPlatform / addCoinRow`。
  - 外觀變化：浮空平台從「細長綠片」改成「方塊草地」（草頂泥身）——這是格子化編輯的必要基礎。
- 🎮 順手三項優化：
  - **R 鍵重玩**這一關（不用重新整理頁面）。
  - **手機 / 平板觸控按鈕**（◀ ▶ 跳，只在觸控裝置顯示）。
  - **多關卡接關**：過關自動進下一關，最後一關顯示「全部破關」（內建第一、二關）。
- （類型：🔴 大修改，新增 `src/levels/levels.js`、`src/scenes/EditorScene.js`，
  連動 `main.js` 與 `PlatformerScene.js`；備份在 `備份/2026-06-02_關卡編輯器與多關卡/`）
